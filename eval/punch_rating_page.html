Punch steering — did it improve the overall sound?

…render server? click a clip, or use the keys: a original · s steered · 1–5 rate · j / k next / previous · m matched/raw
The question per clip: compared with the original (same seed, same prompt, same DoRA), how much did the steering improve the overall sound quality? 1 = worse · 2 = slightly worse · 3 = neutral / no real change · 4 = better · 5 = marked improvement. A more balanced, rounder sound with less coarseness and a present bass counts as better; louder, more compressed or saturated does not, so the steered clip plays level-matched to the original by default (the chips show how much louder / more compressed the raw render is; m toggles raw). Switching between original and steered keeps the playhead.

Renders the unsteered original and the steered clip on the render server (about 20–40 s) and adds the pair to the top of the list. The latch weight scales both guidance gains (bass + body); the preset sets their targets and windows. The original and the steered clip always share one DoRA strength, so only the latch heads differ (the set uses 0.45; the original jobs used 0.45 / 0.51 / 0.61 depending on the job).
