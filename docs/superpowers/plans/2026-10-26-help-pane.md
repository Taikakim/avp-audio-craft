# Help Pane Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A reusable help pane for aavepyora.online pages: glossary terms marked at build time, a docked pane with three-layer
entries, back history and a five-option quiz, and a loader for animation modules; first page the Muon survival guide.

**Architecture:** Python marks terms in the rendered HTML and compiles the glossary (track 1); a dependency-free browser
script renders the pane and quiz from the compiled `glossary.json` (track 2); a shared JS maths library and the first
animation module plug into the pane through a fixed `mount()` interface (track 3). The three tracks share only the
contracts in "Shared contracts" below and can be built in parallel.

**Tech Stack:** Python 3 stdlib (`html.parser`, `json`, `re`, `unittest`/pytest), vanilla ES2022 modules, SVG/canvas,
Node `node --test` for JS maths, Playwright (Python, in `/home/kim/Projects/mir/mir/bin/python`; Chromium installed) for
browser tests.

**Spec:** `docs/superpowers/specs/2026-10-26-help-pane-design.md` (read it first; this plan argues from it).

## Global Constraints

- No third-party JS libraries, no CDN, no build step for JS: plain ES modules served as files.
- No storage of any kind in the browser (no localStorage, sessionStorage, cookies, IndexedDB) and no network calls except
  fetching `glossary.json` and `viz/<id>.js`. Quiz answers are never recorded or sent.
- Nothing is pushed to the public server by any task. Only `publish_blog.py --dry-run` is run.
- Every new script/module starts with `# Owner: WINTERMUTE (created 2026-10-26)` (Python) or `// Owner: WINTERMUTE (created 2026-10-26)` (JS/CSS);
  edits to an existing script add `# Last edited: WINTERMUTE 2026-10-26 -- <what>` under the existing lines.
- Commits: `Misc/agent_commit.sh WINTERMUTE -q -m "..." -- <explicit paths>` from `/home/kim/Projects/SAO`; never `git add -A`;
  `Misc/` is gitignored, so new files there need `git add -f`. Message ends with the two trailer lines
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_013CeGPpfMQ1gjhC89WHXG1t`.
- `glossary/*.json` belongs to CONTINUITY: read it, never edit it.
- Plain-language UI copy (Kim's rule): no shorthand, no number-heavy labels in the pane chrome.

## Review Focus

1. A term that appears inside a word, a URL, an `alt`/`title` attribute or an HTML entity (`&amp;`) must not be marked, and
   the marked HTML must stay valid (no anchor inside an anchor).
2. Overlapping terms and aliases ("LoRA" / "LoRA A", "weight" / "weight decay" / "weight matrix") mark the longest match
   only, every occurrence, case preserved in the visible text.
3. Pane with JavaScript but `glossary.json` failing to load (404 / bad JSON): term clicks still navigate to `glossary.html#id`.
4. A viz module that throws in `mount()` or is missing: the entry still shows its text with "animation unavailable"; the
   pane and article keep working.
5. Keyboard-only and phone-width use: Escape closes, focus returns to the term, the bottom sheet does not trap scrolling of
   the article after it closes.

```python
# Owner: WINTERMUTE (created 2026-10-26)
"""Shared glossary pieces: the blog's inline renderer, entry loading and the build-time validator."""
import html
import json
import re
from pathlib import Path

REQUIRED = ("id", "term", "plain", "quiz")
_SLUG = re.compile(r"^[a-z0-9][a-z0-9-]*$")


def inline(t: str) -> str:
    """Inline syntax shared by blog posts and glossary entries: `code`, **bold**, *em*, [text](https://...)."""
    t = html.escape(t)
    t = re.sub(r"`([^`]+)`", r"<code>\1</code>", t)
    # [text](https://...) links; http(s) only, so a relative or local path in a draft stays visible text
    t = re.sub(r"\[([^\]]+)\]\((https?://[^)\s]+)\)", r'<a href="\2">\1</a>', t)
    t = re.sub(r"\*\*(.+?)\*\*", r"<strong>\1</strong>", t)
    t = re.sub(r"(?<!\*)\*(?!\s)(.+?)(?<!\s)\*(?!\*)", r"<em>\1</em>", t)
    return t


def load_glossary(directory) -> list:
    """All entries of every *.json in `directory` (sorted by file name). Raises ValueError on bad files."""
    entries = []
    for f in sorted(Path(directory).glob("*.json")):
        try:
            data = json.loads(f.read_text(encoding="utf-8"))
        except json.JSONDecodeError as exc:
            raise ValueError(f"{f.name}: not valid JSON ({exc})") from exc
        if not isinstance(data, list):
            raise ValueError(f"{f.name}: the top level must be a JSON list of entries")
        entries.extend(data)
    return entries


def _norm(s: str) -> str:
    return re.sub(r"\s+", " ", s.strip()).lower()


def _is_int(v) -> bool:
    return isinstance(v, int) and not isinstance(v, bool)


def _sentence_count(text: str) -> int:
    text = re.sub(r"`[^`]*`", "x", text).strip()
    return len(re.split(r"(?<=[.!?])\s+(?=[A-Z\"(\[])", text)) if text else 0


def _check_question(label: str, n: int, q, errors: list) -> None:
    where = f"{label}: question {n}"
    if not isinstance(q, dict):
        errors.append(f"{where} is not an object")
        return
    for f in ("q", "options", "answer", "why", "level"):
        if f not in q or q[f] in (None, "", []):
            errors.append(f"{where}: missing required field '{f}'")
    if "level" in q and q["level"] not in (None, "") and not (_is_int(q["level"]) and 1 <= q["level"] <= 3):
        errors.append(f"{where}: level must be 1, 2 or 3")
    opts = q.get("options")
    if opts not in (None, "", []) and not (isinstance(opts, list) and len(opts) == 5):
        got = len(opts) if isinstance(opts, list) else "not a list"
        errors.append(f"{where}: needs exactly 5 options, found {got}")
    ans = q.get("answer")
    if "answer" in q and ans is not None and not (_is_int(ans) and 0 <= ans <= 4):
        errors.append(f"{where}: answer {ans!r} is out of range (0-4)")
    wrong = q.get("wrong")
    if wrong is not None:
        if not isinstance(wrong, dict):
            errors.append(f"{where}: 'wrong' must map option indexes to text")
            return
        for k in wrong:
            if not (isinstance(k, str) and k.isdigit() and 0 <= int(k) <= 4):
                errors.append(f"{where}: 'wrong' key {k!r} is not an option index (0-4)")
            elif _is_int(ans) and int(k) == ans:
                errors.append(f"{where}: 'wrong' is given for the correct option ({k})")


def validate(entries, known_viz, publish: bool, used_ids=None):
    """Check every entry against the spec's build errors. Returns (errors, warnings).

    known_viz: set of animation module names that exist (file stems under site/help/viz/).
    publish:   unknown viz modules and unreviewed quizzes are errors instead of warnings.
    used_ids:  ids of the entries a page actually uses (including entries reachable from them).
               The quiz_reviewed rule applies to these only; None skips the rule.
    """
    errors, warnings = [], []
    seen_ids = {}
    owners = {}          # normalised term/alias -> (entry index, kind)
    for i, e in enumerate(entries):
        if not isinstance(e, dict):
            errors.append(f"entry #{i}: not an object")
            continue
        label = str(e.get("id") or f"entry #{i}")
        for f in REQUIRED:
            if f not in e or e[f] in (None, "", []):
                errors.append(f"{label}: missing required field '{f}'")
        eid = e.get("id")
        if isinstance(eid, str) and eid:
            if not _SLUG.match(eid):
                errors.append(f"{label}: id must be a lowercase slug (a-z, 0-9, hyphen)")
            if eid in seen_ids:
                errors.append(f"{label}: duplicate id (also entry #{seen_ids[eid]})")
            seen_ids.setdefault(eid, i)
        names = []
        if isinstance(e.get("term"), str) and e["term"].strip():
            names.append((e["term"], "term"))
        aliases = e.get("aliases") or []
        if not isinstance(aliases, list):
            errors.append(f"{label}: aliases must be a list")
            aliases = []

            for n, q in enumerate(quiz, 1):
                _check_question(label, n, q, errors)
        elif quiz not in (None, "", []):
            errors.append(f"{label}: quiz must be a list of questions")
        viz = e.get("viz")
        if viz:
            mod = viz.get("module") if isinstance(viz, dict) else None
            if not isinstance(mod, str) or not mod:
                errors.append(f"{label}: viz needs a 'module' name")

            (errors if publish else warnings).append(f"{label}: quiz_reviewed is empty but a page uses this entry")
```

```python
# Owner: WINTERMUTE (created 2026-10-26)
"""Mark glossary terms in rendered HTML: every occurrence becomes <a class="gl" data-term=ID href=...>.

Works on text nodes only (html.parser), so attributes, entities, URLs and skip zones are never touched.
"""
import re
from functools import lru_cache
from html import escape
from html.parser import HTMLParser

SKIP_TAGS = frozenset({"h1", "h2", "h3", "h4", "h5", "h6", "code", "pre", "a", "figcaption", "th", "script", "style"})
_URL = r"(?:https?://|www\.)[^\s<>\"']+"


def _norm(s: str) -> str:
    return re.sub(r"\s+", " ", s.strip()).lower()


def _plurals(form: str) -> list:
    low = form.lower()
    if len(low) > 1 and low.endswith("y") and low[-2] not in "aeiou":
        return [form[:-1] + "ies"]
    if low.endswith(("s", "x", "z", "ch", "sh")):
        return [form + "es"]
    return [form + "s"]


@lru_cache(maxsize=16)
def _matcher(key):
    """key = ((id, term, (aliases...)), ...) -> (compiled regex or None, {normalised variant: id})."""
    variants = {}
    for eid, term, aliases in key:                      # explicit forms win over generated plurals
        for f in (term,) + aliases:
            variants.setdefault(_norm(f), eid)
    for eid, term, aliases in key:
        for f in (term,) + aliases:
            for p in _plurals(f):
                variants.setdefault(_norm(p), eid)
    if not variants:
        return None, variants
    body = "|".join(re.escape(v).replace(r"\ ", r"\s+") for v in sorted(variants, key=len, reverse=True))
    rx = re.compile(rf"(?P<url>{_URL})|(?<![\w/@.#-])(?P<t>{body})(?![\w@]|[/.-]\w)", re.I)
    return rx, variants


class _Marker(HTMLParser):
    def __init__(self, rx, variants, href, exclude_id):
        super().__init__(convert_charrefs=False)
        self.rx, self.variants, self.href, self.exclude_id = rx, variants, href, exclude_id
        self.out, self.skip = [], 0

    def handle_starttag(self, tag, attrs):
        self.out.append(self.get_starttag_text())
        if tag in SKIP_TAGS:
            self.skip += 1

    def handle_startendtag(self, tag, attrs):
        self.out.append(self.get_starttag_text())

    def handle_endtag(self, tag):
        self.out.append(f"</{tag}>")
        if tag in SKIP_TAGS and self.skip:
            self.skip -= 1

    def handle_entityref(self, name):
        self.out.append(f"&{name};")

    def handle_charref(self, name):
        self.out.append(f"&#{name};")

    def handle_comment(self, data):
        self.out.append(f"<!--{data}-->")

    def handle_decl(self, decl):
        self.out.append(f"<!{decl}>")

    def handle_pi(self, data):
        self.out.append(f"<?{data}>")

    def unknown_decl(self, data):
        self.out.append(f"<![{data}]>")

    def handle_data(self, data):
        self.out.append(data if self.skip else self.rx.sub(self._sub, data))

    def _sub(self, m):
        if m.group("url"):
            return m.group(0)
        text = m.group("t")
        eid = self.variants.get(_norm(text))
        if eid is None or eid == self.exclude_id:
            return text                                  # own term: consumed (longest match) but not linked
        e = escape(eid, quote=True)
        return f'<a class="gl" data-term="{e}" href="{escape(self.href, quote=True)}#{e}">{text}</a>'


def mark(html: str, glossary, glossary_href: str = "../help/glossary.html", exclude_id=None) -> str:
    """Return `html` with every glossary term occurrence wrapped as <a class="gl" ...> (contract C2).

    glossary: list of entry dicts (needs id, term, optional aliases). exclude_id: the entry whose own
    term must not be linked (used when marking that entry's own text).
    """
    key = tuple((e["id"], e["term"], tuple(e.get("aliases") or ())) for e in glossary)
    rx, variants = _matcher(key)
    if rx is None:
        return html
    p = _Marker(rx, variants, glossary_href, exclude_id)
    p.feed(html)
    p.close()
    return "".join(p.out)


class _Used(HTMLParser):
    def __init__(self):
        super().__init__(convert_charrefs=False)
        self.ids = set()

    def handle_starttag(self, tag, attrs):
        if tag == "a":
            d = dict(attrs)
            if "gl" in (d.get("class") or "").split() and d.get("data-term"):
                self.ids.add(d["data-term"])


def used_ids(html: str) -> set:
    """The entry ids that `html` links as marked terms."""
    p = _Used()
    p.feed(html)
    p.close()
    return p.ids
```

```python
#!/usr/bin/env python3
# Owner: WINTERMUTE (created 2026-10-26)
"""Validate the glossary and write help/glossary.json (what the pane fetches) and help/glossary.html
(every entry readable without JavaScript, one anchor per entry id).

  build_page.py --out /tmp/x/help [--glossary-dir SAO/glossary] [--viz-dir SAO/site/help/viz] [--publish]

Exit 1 on errors (nothing is written), warnings are printed. Contract C4 describes glossary.json.
"""
import argparse
import html
import json
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE.parent))
from glossary.glossary_lib import inline, load_glossary, validate   # noqa: E402
from glossary.mark import mark, used_ids                           # noqa: E402
import build_site as bs                                            # noqa: E402

SAO = HERE.parent.parent
DEFAULT_GLOSSARY = SAO / "glossary"
DEFAULT_VIZ = SAO / "site" / "help" / "viz"


def known_viz(viz_dir) -> set:
    """Contract C6: the .js file stems directly under viz/ (not lib/)."""
    d = Path(viz_dir)
    return {p.stem for p in d.glob("*.js")} if d.is_dir() else set()


def compile_entries(entries) -> dict:
    """Contract C4 `entries` mapping: inline syntax rendered, other terms marked, own term left plain."""
    out = {}
    for e in entries:
        own = e["id"]

        def t(s, own=own):
            return mark(inline(s), entries, glossary_href="glossary.html", exclude_id=own) if s else ""

        quiz = []
        for q in sorted(e["quiz"], key=lambda q: q["level"]):          # sorted() is stable
            quiz.append({"level": q["level"], "q": t(q["q"]), "options": [inline(o) for o in q["options"]],   # options are not term-marked (C4 amendment)
                         "answer": q["answer"], "why": t(q["why"]),
                         "wrong": {str(k): t(v) for k, v in (q.get("wrong") or {}).items()}})
        out[own] = {"term": e["term"], "plain": t(e["plain"]), "ours": t(e.get("ours")),
                    "deeper": t(e.get("deeper")),
                    "papers": [{"title": p["title"], "url": p["url"]} for p in (e.get("papers") or [])],
                    "viz": e.get("viz") or None, "quiz": quiz}
    return out


def reachable(ids, compiled) -> set:
    """`ids` plus every entry reachable by following marked terms in the compiled entry text."""
    seen, todo = set(), list(ids)
    while todo:
        i = todo.pop()
        if i in seen or i not in compiled:
            continue
        seen.add(i)
        e = compiled[i]
        texts = [e["plain"], e["ours"], e["deeper"]]
        for q in e["quiz"]:
            texts += [q["q"], q["why"], *q["options"], *q["wrong"].values()]
        for text in texts:
            todo.extend(used_ids(text))
    return seen


def render_glossary_html(entries, compiled) -> str:
    doc = bs.head("Glossary — Vibe on The Edg3", css="../edg3.css")
    doc += bs.masthead("reference", f"{len(entries)} terms")
    toc = "\n".join(f'<li><a href="#{html.escape(e["id"], quote=True)}">{html.escape(e["term"])}</a></li>'
                    for e in sorted(entries, key=lambda e: e["term"].casefold()))
    parts = [f'<article class="blog-post glossary">\n<h1>Glossary</h1>\n<ul class="gl-toc">\n{toc}\n</ul>']
    for e in entries:
        c = compiled[e["id"]]
        s = [f'<section class="gl-entry" id="{html.escape(e["id"], quote=True)}">',
             f'<h2>{html.escape(e["term"])}</h2>', f'<p class="gl-plain">{c["plain"]}</p>']
        if c["ours"]:
            s.append(f'<h3>In our models</h3>\n<p>{c["ours"]}</p>')
        if c["deeper"]:
            s.append(f'<details><summary>Going deeper</summary>\n<p>{c["deeper"]}</p>\n</details>')
        links = [p for p in c["papers"] if str(p["url"]).startswith(("http://", "https://"))]
        if links:
            s.append("<h3>Papers</h3>\n<ul>\n" + "\n".join(
                f'<li><a href="{html.escape(p["url"], quote=True)}">{html.escape(p["title"])}</a></li>'
                for p in links) + "\n</ul>")
        qs = []
        for q in c["quiz"]:
            letters = "ABCDE"
            opts = "".join(f"<li>{o}</li>" for o in q["options"])
            notes = "".join(f'<p>If you chose {letters[int(k)]}: {v}</p>' for k, v in q["wrong"].items())
            qs.append(f'<li><p>{q["q"]}</p><ol type="A">{opts}</ol>'
                      f'<p><strong>Answer: {letters[q["answer"]]}.</strong> {q["why"]}</p>{notes}</li>')
        s.append(f'<details class="gl-quiz"><summary>Check your understanding ({len(c["quiz"])} questions)'
                 f'</summary>\n<ol>\n{chr(10).join(qs)}\n</ol>\n</details>')
        s.append("</section>")
        parts.append("\n".join(s))
    return doc + "\n".join(parts) + "\n</article>\n</div></body></html>\n"


def build(glossary_dir, viz_dir, out, publish: bool = False, used_ids=None):
    """Validate and write glossary.json + glossary.html into `out`. Returns (errors, warnings);
    nothing is written when there are errors."""
    try:
        entries = load_glossary(glossary_dir)
    except ValueError as exc:
        return [str(exc)], []
    errors, warnings = validate(entries, known_viz(viz_dir), publish, used_ids)
    if errors:
        return errors, warnings
    compiled = compile_entries(entries)
    out = Path(out)
    out.mkdir(parents=True, exist_ok=True)
    (out / "glossary.json").write_text(
        json.dumps({"version": 1, "entries": compiled}, ensure_ascii=False, indent=1), encoding="utf-8")
    (out / "glossary.html").write_text(render_glossary_html(entries, compiled), encoding="utf-8")
    return errors, warnings


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__.split("\n")[1])
    ap.add_argument("--glossary-dir", default=str(DEFAULT_GLOSSARY))
    ap.add_argument("--viz-dir", default=str(DEFAULT_VIZ))
    ap.add_argument("--out", required=True)
    ap.add_argument("--publish", action="store_true",
                    help="unknown viz modules are errors (default: warnings)")
    a = ap.parse_args(argv)
    errors, warnings = build(a.glossary_dir, a.viz_dir, a.out, publish=a.publish)
    for w in warnings:
        print(f"WARNING: {w}")
    for err in errors:
        print(f"ERROR: {err}")
    if errors:
        return 1
    print(f"wrote {a.out}/glossary.json and glossary.html")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
def build_help_dir(out: Path, glossary_dir, publish: bool, page_used_ids) -> None:
    """Assemble the help/ directory: site/help/* files, then glossary.json + glossary.html.

    page_used_ids: the entry ids the pane pages link. The quiz_reviewed rule applies to those and to
    every entry reachable from them through the pane's own links. Exits (REFUSING) on any glossary
    error and when glossary.html/json would leak a path or be altered by redact().
    """
    out = Path(out)
    if SITE_HELP.is_dir():
        shutil.copytree(SITE_HELP, out, dirs_exist_ok=True, ignore=shutil.ignore_patterns(*_HELP_IGNORE))
    viz_dir = SITE_HELP / "viz"
    try:
        entries = gl.load_glossary(glossary_dir)
    except ValueError as exc:
        sys.exit(f"REFUSING: glossary unreadable: {exc}")
    errors, _ = gl.validate(entries, gbuild.known_viz(viz_dir), publish)
    if errors:
        sys.exit("REFUSING: glossary errors:\n  " + "\n  ".join(errors))
    used = gbuild.reachable(page_used_ids, gbuild.compile_entries(entries))
    errors, warnings = gbuild.build(glossary_dir, viz_dir, out, publish=publish, used_ids=used)
    for w in warnings:
        print(f"WARNING (glossary): {w}")
    if errors:
        sys.exit("REFUSING: glossary errors:\n  " + "\n  ".join(errors))
    for name in ("glossary.html", "glossary.json"):
        text = (out / name).read_text(encoding="utf-8")
        leaks = sorted({L for L in LEAK if L in text})
        if leaks or redact(text) != text:
            sys.exit(f"REFUSING: help/{name} leaks {leaks or 'text that redact() would change'}")
    print(f"help/: {len(used)} glossary entries used by the pane pages, glossary.json + glossary.html CLEAN")
```

```python
import html

from playwright.sync_api import expect

TAG = re.compile(r"<[^>]+>")


def plain_text(markup):
    """Visible text of an HTML snippet from glossary.json, whitespace-normalised."""
    return " ".join(html.unescape(TAG.sub("", markup or "")).split())


def load_page(page, url):
    """goto + wait until help-pane.js has finished starting (the pane element exists)."""
    page.goto(url)
    page.locator("#help-pane").wait_for(state="attached")


def term_link(page, term, which="first"):
    loc = page.locator(f'a.gl[data-term="{term}"]')
    return loc.first if which == "first" else loc.last


def open_via_click(page, page_url, term, which="first"):
    load_page(page, page_url)
    link = term_link(page, term, which)
    link.click()
    expect(page.locator("#help-pane")).to_be_visible()
```

```js
// Owner: WINTERMUTE (created 2026-10-26)
// help-pane.js: docked help pane for glossary terms (spec 2026-10-26-help-pane-design.md, section 6).
// Plain ES module, no dependencies. Reads <script type="module" data-glossary data-viz-base> (contract C3),
// fetches glossary.json (C4) once, and loads animation modules (C5) on demand.
// It stores nothing (no localStorage, cookies, IndexedDB) and sends nothing except those two kinds of fetch.
// If glossary.json cannot be loaded, or this script throws, no click handler exists and the links keep
// navigating to glossary.html: reading is never blocked.

const PHONE_QUERY = '(max-width: 700px)';
const SEEN = 'gl-seen';
const isPhone = () => window.matchMedia(PHONE_QUERY).matches;

function el(tag, cls, text) {
  const n = document.createElement(tag);
  if (cls) n.className = cls;
  if (text != null) n.textContent = text;
  return n;
}

// markup comes from glossary.json, which the build has already rendered and leak-scanned (C4)
function rich(tag, cls, markup) {
  const n = el(tag, cls);
  n.innerHTML = markup;
  return n;
}

function btn(cls, label) {
  const b = el('button', cls, label);
  b.type = 'button';
  return b;
}

class HelpPane {
  constructor(entries, vizBase) {
    this.entries = entries;
    this.vizBase = vizBase;
    this.trail = [];          // [{id, mode: 'entry' | 'quiz', quiz: null | {...}}], this visit only, in memory
    this.isOpen = false;
    this.lastTrigger = null;  // the page link that opened the pane, so closing can return focus to it
    this.token = 0;           // bumped on every render and close; stale async viz loads compare against it
    this.viz = null;          // {handle, wrap} of the mounted animation
    this.overlay = null;      // the enlarge overlay, if open
    this.seen = new Set();    // terms opened during this visit
  }

  top() { return this.trail[this.trail.length - 1] || null; }

  has(id) { return Object.prototype.hasOwnProperty.call(this.entries, id); }

  install() {
    const pane = (this.pane = el('aside', 'hp-pane'));
    pane.id = 'help-pane';
    pane.hidden = true;
    pane.setAttribute('aria-labelledby', 'hp-title');

    this.head = el('div', 'hp-head');
    const grip = el('span', 'hp-grip');
    grip.setAttribute('aria-hidden', 'true');
    this.backBtn = btn('hp-back', 'Back');
    this.backBtn.setAttribute('aria-label', 'Back to the previous term');
    this.backBtn.disabled = true;
    this.titleEl = el('h2', 'hp-title');
    this.titleEl.id = 'hp-title';
    this.titleEl.tabIndex = -1;
    this.closeBtn = btn('hp-close', 'Close');
    this.closeBtn.setAttribute('aria-label', 'Close help');
    this.head.append(grip, this.backBtn, this.titleEl, this.closeBtn);

    this.bodyEl = el('div', 'hp-body');
    this.live = el('div', 'hp-live');
    this.live.setAttribute('role', 'status');
    this.live.setAttribute('aria-live', 'polite');
    pane.append(this.head, this.bodyEl, this.live);

    this.reopenBtn = btn('hp-reopen', 'Reopen help');
    this.reopenBtn.hidden = true;
    document.body.append(pane, this.reopenBtn);

    this.backBtn.addEventListener('click', () => this.back());
    this.closeBtn.addEventListener('click', () => this.close());
    this.reopenBtn.addEventListener('click', () => this.reopen());
    document.addEventListener('click', (e) => this.onDocClick(e));
    document.addEventListener('keydown', (e) => this.onKey(e));
    window.addEventListener('hashchange', () => this.openFromHash(false));
    this.installSwipe();
    this.openFromHash(true);
  }

  // ---- events -------------------------------------------------------------------------------------------

  onDocClick(e) {
    if (e.defaultPrevented || e.button !== 0 || e.metaKey || e.ctrlKey || e.shiftKey || e.altKey) return;
    const a = e.target instanceof Element ? e.target.closest('a.gl') : null;
    if (!a) return;
    const id = a.dataset.term || (a.hash || '').replace(/^#/, '');
    if (!this.has(id)) return;          // unknown term: let the link navigate to glossary.html
    e.preventDefault();
    this.open(id, a);
  }

  onKey(e) {
    if (e.key !== 'Escape' || e.defaultPrevented) return;
    if (this.overlay) { e.preventDefault(); this.closeOverlay(true); return; }
    if (this.isOpen) { e.preventDefault(); this.close(); }
  }

  // ---- opening, closing, history -------------------------------------------------------------------------

  open(id, trigger) {
    if (!this.has(id)) return false;
    const fromPage = trigger && !this.pane.contains(trigger);
    if (fromPage) this.lastTrigger = trigger;
    const t = this.top();
    if (!(t && t.id === id && t.mode === 'entry')) this.trail.push({ id, mode: 'entry', quiz: null });
    this.show();
    if (fromPage) this.revealTrigger(trigger);
    return true;
  }

  show() {
    this.isOpen = true;
    this.pane.hidden = false;
    document.body.classList.add('help-pane-open');
    this.reopenBtn.hidden = true;
    this.render();
    this.syncHash();
    this.titleEl.focus({ preventScroll: true });
  }

  reopen() {
    if (this.top()) this.show();
  }

  close() {
    if (!this.isOpen) return;
    this.closeOverlay(false);
    this.destroyViz();
    this.token++;                       // abandon any animation still loading
    this.isOpen = false;
    this.pane.hidden = true;
    this.pane.style.transform = '';
    this.pane.style.transition = '';
    document.body.classList.remove('help-pane-open');
    this.reopenBtn.hidden = !this.trail.length;
    this.syncHash();
    const t = this.lastTrigger;
    if (t && t.isConnected) t.focus({ preventScroll: true });
    else if (!this.reopenBtn.hidden) this.reopenBtn.focus({ preventScroll: true });
  }

  back() {
    if (this.trail.length <= 1) return;
    this.trail.pop();
    this.render();
    this.syncHash();
    this.titleEl.focus({ preventScroll: true });
  }

  // ---- rendering -----------------------------------------------------------------------------------------

  render() {
    this.token++;
    this.closeOverlay(false);
    this.destroyViz();
    const item = this.top();
    if (!item) return;
    const entry = this.entries[item.id];
    this.titleEl.textContent = entry.term;
    this.backBtn.disabled = this.trail.length <= 1;
    this.bodyEl.replaceChildren();
    if (item.mode === 'quiz') this.renderQuiz(entry, item);
    else this.renderEntry(entry);
    this.bodyEl.scrollTop = 0;
    this.markSeen(item.id);
  }

  markSeen(id) {
    this.seen.add(id);
    document.querySelectorAll('a.gl').forEach((a) => {
      if (this.seen.has(a.dataset.term)) a.classList.add(SEEN);
    });
  }

  // STUB: Task 2.3 replaces this with the full three-layer layout.
  renderEntry(entry) {
    this.bodyEl.append(rich('p', 'hp-plain', entry.plain));
  }

  // STUB: Task 2.4 replaces this.
  renderQuiz() {}

  // STUB: Task 2.3 replaces this.
  closeOverlay() {}

  // STUB: Task 2.5 replaces this.
  installSwipe() {}

  destroyViz() {
    const v = this.viz;
    this.viz = null;
    if (!v) return;
    try {
      if (v.handle && typeof v.handle.destroy === 'function') v.handle.destroy();
    } catch (err) { /* a broken destroy() must not block navigation */ }
  }

  helpApi() {
    const cs = getComputedStyle(document.documentElement);
    const v = (name, fallback) => cs.getPropertyValue(name).trim() || fallback;
    return {
      colors: {
        accent: v('--edge', '#0f9e99'),
        fg: v('--ink', '#2b3538'),
        muted: v('--dim', '#7a8a8e'),
        bg: v('--paper', '#fafaf7'),
        good: v('--hp-good', '#2e7d4f'),
        bad: v('--hp-bad', '#b3412e'),
      },
      openTerm: (id) => { this.open(id, null); },
      reducedMotion: window.matchMedia('(prefers-reduced-motion: reduce)').matches,
    };
  }

  // ---- address bar ---------------------------------------------------------------------------------------

  syncHash() {
    const t = this.top();
    const want = this.isOpen && t ? '#gl=' + encodeURIComponent(t.id) : '';
    if (!want && !location.hash.startsWith('#gl=')) return;   // never wipe someone else's anchor
    if (location.hash === want) return;
    history.replaceState(history.state, '', location.pathname + location.search + want);
  }

  openFromHash() {
    const m = /^#gl=(.+)$/.exec(location.hash);
    if (!m) return;
    let id;
    try { id = decodeURIComponent(m[1]); } catch (err) { return; }
    if (!this.has(id)) return;
    const t = this.top();
    if (this.isOpen && t && t.id === id) return;
    this.open(id, null);
  }

  // Keep the clicked term in view: beside the docked pane it may have moved; above a bottom sheet it may be
  // hidden underneath it.
  revealTrigger(a) {
    requestAnimationFrame(() => {
      if (!a.isConnected) return;
      const r = a.getBoundingClientRect();
      if (isPhone()) {
        const limit = window.innerHeight * 0.3;      // the sheet covers the lower 70%
        if (r.bottom > limit || r.top < 0) {
          window.scrollBy({ top: r.top - window.innerHeight * 0.08, behavior: 'instant' });
        }
      } else if (r.top < 0 || r.bottom > window.innerHeight) {
        a.scrollIntoView({ block: 'center' });
      }
    });
  }
}

async function start(scriptEl) {
  const glossaryUrl = new URL(scriptEl.dataset.glossary, document.baseURI).href;
  const vizBase = new URL(scriptEl.dataset.vizBase || 'viz/', document.baseURI).href;
  let data;
  try {
    const r = await fetch(glossaryUrl);
    if (!r.ok) return;
    data = await r.json();
  } catch (err) {
    return;                                  // links stay plain links to glossary.html
  }
  if (!data || typeof data.entries !== 'object' || data.entries === null) return;
  new HelpPane(data.entries, vizBase).install();
}

const scriptEl = document.querySelector('script[type="module"][data-glossary]');
if (scriptEl) {
  start(scriptEl).catch(() => { /* a script error leaves the article untouched */ });
}
```

```js
  // Swipe down on the header dismisses the bottom sheet. Only the header listens, so the pane body and the
  // page keep their normal touch scrolling; nothing here locks page scroll.
  installSwipe() {
    const head = this.head;
    const pane = this.pane;
    let startY = 0;
    let dy = 0;
    let dragging = false;
    head.addEventListener('touchstart', (e) => {
      if (!isPhone() || e.touches.length !== 1) return;
      startY = e.touches[0].clientY;
      dy = 0;
      dragging = true;
      pane.style.transition = 'none';
    }, { passive: true });
    head.addEventListener('touchmove', (e) => {
      if (!dragging) return;
      dy = Math.max(0, e.touches[0].clientY - startY);
      pane.style.transform = `translateY(${dy}px)`;
    }, { passive: true });
    const end = () => {
      if (!dragging) return;
      dragging = false;
      pane.style.transition = '';
      pane.style.transform = '';
      if (dy > 80) this.close();
      dy = 0;
    };
    head.addEventListener('touchend', end);
    head.addEventListener('touchcancel', end);
  }
```

```js
// Owner: WINTERMUTE (created 2026-10-26)
// Seeded randomness and the minibatch-gradient noise model. Pure functions, no DOM.
export function mulberry32(seed) {
  let a = seed >>> 0;
  return function () {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

// Standard normal numbers from a uniform generator (Box-Muller, spare value cached).
export function makeGauss(rng) {
  let spare = null;
  return function () {
    if (spare !== null) { const s = spare; spare = null; return s; }
    let u = 0;
    while (u === 0) u = rng();
    const v = rng();
    const rad = Math.sqrt(-2 * Math.log(u));
    spare = rad * Math.sin(2 * Math.PI * v);
    return rad * Math.cos(2 * Math.PI * v);
  };
}
```

```js
import { zeros } from '../lib/optim.js';

// n random orthonormal vectors (Gram-Schmidt of gaussian vectors).
export function orth(n, gauss) {
  const Q = [];
  for (let i = 0; i < n; i++) {
    let v = Array.from({ length: n }, () => gauss());
    for (const q of Q) {
      const d = v.reduce((s, x, k) => s + x * q[k], 0);
      v = v.map((x, k) => x - d * q[k]);
    }
    const nv = Math.sqrt(v.reduce((s, x) => s + x * x, 0));
    Q.push(v.map((x) => x / nv));
  }
  return Q;
}
// An r x c matrix whose singular values are exactly svs (length min(r, c)).
export function withSingularValues(r, c, svs, gauss) {
  const U = orth(r, gauss), V = orth(c, gauss);
  const M = zeros(r, c);
  svs.forEach((s, k) => {
    for (let i = 0; i < r; i++) for (let j = 0; j < c; j++) M[i][j] += s * U[k][i] * V[k][j];
  });
  return M;
}
```

```js
// Owner: WINTERMUTE (created 2026-10-26)
// Update maths for the help-pane animations. Pure functions, no DOM.
// A "matrix" is an array of rows (arrays of numbers). Convention: an optimiser's `update`
// is the amount SUBTRACTED from the weights (w_new = w - update).

export const NS_COEFFS = [3.4445, -4.7750, 2.0315];

// ---------------------------------------------------------------- matrix helpers
export function zeros(r, c) {
  return Array.from({ length: r }, () => new Array(c).fill(0));
}
export function shape(M) { return [M.length, M[0].length]; }
export function map(M, f) { return M.map((row) => row.map((x) => f(x))); }
export function map2(A, B, f) { return A.map((row, i) => row.map((x, j) => f(x, B[i][j]))); }
export function scale(M, s) { return map(M, (x) => x * s); }
export function add(A, B) { return map2(A, B, (x, y) => x + y); }
export function transpose(M) {
  const [r, c] = shape(M);
  const T = zeros(c, r);
  for (let i = 0; i < r; i++) for (let j = 0; j < c; j++) T[j][i] = M[i][j];
  return T;
}
export function matmul(A, B) {
  const [r, k] = shape(A);
  const [k2, c] = shape(B);
  if (k !== k2) throw new Error(`matmul shape mismatch ${r}x${k} * ${k2}x${c}`);
  const C = zeros(r, c);
  for (let i = 0; i < r; i++)
    for (let p = 0; p < k; p++) {
      const a = A[i][p];
      if (a === 0) continue;
      for (let j = 0; j < c; j++) C[i][j] += a * B[p][j];
    }
  return C;
}
export function frobenius(M) {
  let s = 0;
  for (const row of M) for (const x of row) s += x * x;
  return Math.sqrt(s);
}
export function meanAbs(M) {
  let s = 0, n = 0;
  for (const row of M) for (const x of row) { s += Math.abs(x); n++; }
  return s / n;
}

// Eigenvalues of a symmetric matrix by cyclic Jacobi rotations (adequate for <= 16x16).
function symmetricEigenvalues(S) {
  const n = S.length;
  const A = S.map((row) => row.slice());
  for (let sweep = 0; sweep < 60; sweep++) {
    let off = 0;
    for (let i = 0; i < n; i++) for (let j = 0; j < n; j++) if (i !== j) off += A[i][j] * A[i][j];
    if (off < 1e-24) break;
    for (let p = 0; p < n - 1; p++)
      for (let q = p + 1; q < n; q++) {
        const apq = A[p][q];
        if (Math.abs(apq) < 1e-300) continue;
        const theta = (A[q][q] - A[p][p]) / (2 * apq);
        const t = (theta >= 0 ? 1 : -1) / (Math.abs(theta) + Math.sqrt(theta * theta + 1));
        const c = 1 / Math.sqrt(t * t + 1);
        const s = t * c;
        for (let k = 0; k < n; k++) {
          const akp = A[k][p], akq = A[k][q];
          A[k][p] = c * akp - s * akq;
          A[k][q] = s * akp + c * akq;
        }
        for (let k = 0; k < n; k++) {
          const apk = A[p][k], aqk = A[q][k];
          A[p][k] = c * apk - s * aqk;
          A[q][k] = s * apk + c * aqk;
        }
      }
  }
  return A.map((row, i) => row[i]);
}

// Singular values, largest first. Uses the smaller of M^T M and M M^T.
export function singularValues(M) {
  const [r, c] = shape(M);
  const S = r >= c ? matmul(transpose(M), M) : matmul(M, transpose(M));
  return symmetricEigenvalues(S).map((e) => Math.sqrt(Math.max(e, 0))).sort((a, b) => b - a);
}
```

```js
// Our measured numbers: cosine between the gradients of two half batches (32 + 32 of a batch of 64).
export const CALIBRATION = {
  batch: 64,
  early: 0.37,
  late: 0.08,
  source: 'EB64 half-batch gradient cosine, onset head, 2026-10-22',
};

export function randnMatrix(r, c, gauss) {
  const M = zeros(r, c);
  for (let i = 0; i < r; i++) for (let j = 0; j < c; j++) M[i][j] = gauss();
  return M;
}

// Noise model: one example's gradient = true gradient + sigma1 * z (per element, z standard normal);
// a minibatch of B examples averages that noise down by sqrt(B).
export function minibatchNoiseStd(sigma1, B) { return sigma1 / Math.sqrt(B); }
export function minibatchGrad(gTrue, sigma1, B, gauss) {
  const s = minibatchNoiseStd(sigma1, B);
  return gTrue.map((row) => row.map((g) => g + s * gauss()));
}

// Two independent half batches (B/2 each) have cosine delta^2 / (1 + delta^2), delta = |g| / |noise of a half batch|.
// gRms = rms of the true gradient per element; sigma1 is in the same units.
export function halfBatchCosine(sigma1, B = CALIBRATION.batch, gRms = 1) {
  const delta = (gRms * Math.sqrt(B / 2)) / sigma1;
  return (delta * delta) / (1 + delta * delta);
}
export function sigmaForHalfBatchCosine(c, B = CALIBRATION.batch, gRms = 1) {
  if (!(c > 0 && c < 1)) throw new Error('cosine must be in (0, 1)');
  const delta = Math.sqrt(c / (1 - c));
  return (gRms * Math.sqrt(B / 2)) / delta;
}
```

```js
// ---------------------------------------------------------------- AdamW
// state: null on the first call, else the `state` returned by the previous call.
// opts.w: current weights, only needed when wd > 0 (decoupled weight decay).
export function adamwStep(state, grad, opts = {}) {
  const { lr = 1e-3, beta1 = 0.9, beta2 = 0.999, eps = 1e-8, wd = 0, w = null } = opts;
  const [r, c] = shape(grad);
  const prev = state ?? { t: 0, m: zeros(r, c), v: zeros(r, c) };
  const t = prev.t + 1;
  const m = map2(prev.m, grad, (m0, g) => beta1 * m0 + (1 - beta1) * g);
  const v = map2(prev.v, grad, (v0, g) => beta2 * v0 + (1 - beta2) * g * g);
  const c1 = 1 - Math.pow(beta1, t);
  const c2 = 1 - Math.pow(beta2, t);
  const update = m.map((row, i) => row.map((mi, j) => {
    const adaptive = (mi / c1) / (Math.sqrt(v[i][j] / c2) + eps);
    const decay = wd > 0 && w ? wd * w[i][j] : 0;
    return lr * (adaptive + decay);
  }));
  return { update, state: { t, m, v } };
}

// ---------------------------------------------------------------- Newton-Schulz / Muon
// Quintic iteration X <- a X + (b A + c A^2) X with A = X X^T. Frobenius-normalise first;
// work on the wide orientation (rows <= cols) like the reference Muon code.
export function newtonSchulz(M, iters = 5, coeffs = NS_COEFFS) {
  const [a, b, c] = coeffs;
  const [r, cc] = shape(M);
  const tall = r > cc;
  let X = scale(M, 1 / (frobenius(M) + 1e-7));
  if (tall) X = transpose(X);
  for (let k = 0; k < iters; k++) {
    const A = matmul(X, transpose(X));
    const B = add(scale(A, b), scale(matmul(A, A), c));
    X = add(scale(X, a), matmul(B, X));
  }
  return tall ? transpose(X) : X;
}
export function newtonSchulz5(M) { return newtonSchulz(M, 5, NS_COEFFS); }

// scaleMode: 'moonlight' = 0.2*sqrt(max(rows, cols)) (every matrix moves ~0.2*lr per weight, like AdamW);
//            'keller'    = sqrt(max(1, rows/cols)) (original Muon code); 'none' = 1.
export function muonScale(rows, cols, mode) {
  if (mode === 'moonlight') return 0.2 * Math.sqrt(Math.max(rows, cols));
  if (mode === 'keller') return Math.sqrt(Math.max(1, rows / cols));
  return 1;
}
export function muonStep(state, grad, opts = {}) {
  const { lr = 0.02, momentum = 0.95, scaleMode = 'moonlight' } = opts;
  const [r, c] = shape(grad);
  const prev = state ?? { buf: zeros(r, c) };
  const buf = map2(prev.buf, grad, (b0, g) => momentum * b0 + g);
  const o = newtonSchulz5(buf);
  const update = scale(o, lr * muonScale(r, c, scaleMode));
  return { update, state: { buf } };
}
```

```js
// The optimiser's own readout: root-mean-square of m / sqrt(v) over all elements
// (about 1 for a clean signal, about sqrt((1-b)/(1+b)) = 0.23 for pure noise at beta 0.9).
export function snrGate(m, v, eps = 1e-12) {
  let s = 0, n = 0;
  map2(m, v, (mi, vi) => { const r = mi / Math.sqrt(vi + eps); s += r * r; n++; return 0; });
  return Math.sqrt(s / n);
}
```

```js
// ---------------------------------------------------------------- number formats
// minExp = exponent of the smallest normal number (subnormals share its spacing).
export const DTYPES = {
  fp32: { mant: 23, minExp: -126, max: 3.4028234663852886e38, label: 'fp32' },
  bf16: { mant: 7, minExp: -126, max: 3.3895313892515355e38, label: 'bf16' },
  fp16: { mant: 10, minExp: -14, max: 65504, label: 'fp16' },
  fp8e4m3: { mant: 3, minExp: -6, max: 448, label: 'fp8 (e4m3)' },
};

const f32 = new Float32Array(1);
const u32 = new Uint32Array(f32.buffer);

function roundHalfEven(x) {
  const f = Math.floor(x);
  const d = x - f;
  if (d < 0.5) return f;
  if (d > 0.5) return f + 1;
  return f % 2 === 0 ? f : f + 1;
}
function exponentOf(a) {
  let e = Math.floor(Math.log2(a));
  while (Math.pow(2, e) > a) e--;
  while (Math.pow(2, e + 1) <= a) e++;
  return e;
}
// Generic round-to-nearest-even onto a (mant, minExp, max) grid. Overflow: fp8 saturates, others go to infinity.
function quantize(x, dt, saturate) {
  if (!Number.isFinite(x) || x === 0) return x;
  const sign = x < 0 ? -1 : 1;
  const a = Math.abs(x);
  const e = Math.max(exponentOf(a), dt.minExp);
  const spacing = Math.pow(2, e - dt.mant);
  const q = roundHalfEven(a / spacing) * spacing;
  if (q > dt.max) return sign * (saturate ? dt.max : Infinity);
  return sign * q;
}
function roundBf16(x) {
  f32[0] = x;
  let b = u32[0];
  if (((b >>> 23) & 0xff) === 0xff) return f32[0]; // inf / nan
  b = (b + 0x7fff + ((b >>> 16) & 1)) >>> 0;
  u32[0] = (b & 0xffff0000) >>> 0;
  return f32[0];
}

export function roundTo(x, dtype) {
  switch (dtype) {
    case 'fp32': return Math.fround(x);
    case 'bf16': return roundBf16(x);
    case 'fp16': return quantize(x, DTYPES.fp16, false);
    case 'fp8e4m3': return quantize(x, DTYPES.fp8e4m3, true);
    default: throw new Error(`unknown dtype ${dtype}`);
  }
}
// Spacing between representable numbers around |w|.
export function ulp(w, dtype) {
  const dt = DTYPES[dtype];
  if (!dt) throw new Error(`unknown dtype ${dtype}`);
  const a = Math.abs(w);
  if (a === 0) return Math.pow(2, dt.minExp - dt.mant);
  return Math.pow(2, Math.max(exponentOf(a), dt.minExp) - dt.mant);
}
// Does storing w + dw in this format change the stored weight at all?
export function survivesUpdate(w, dw, dtype) {
  if (dw === 0) return false;
  const stored = roundTo(w, dtype);
  return roundTo(stored + dw, dtype) !== stored;
}
```

```js
// The scenarios behind the step-size animation: one gradient stream feeds AdamW and Muon side by side.
import { adamwStep, muonStep, meanAbs, scale } from './optim.js';
import {
  mulberry32, makeGauss, randnMatrix, CALIBRATION, sigmaForHalfBatchCosine, minibatchNoiseStd,
} from './noise.js';

export const STEP_AT = 150;     // step at which "drops" / "rises" happen
export const TOTAL_STEPS = 450;
export const LR = 3e-4;         // AdamW's best learning rate for our heads (guide section 4)
export const WEIGHT_RMS = 0.05; // illustrative weight size

export const SCENARIOS = {
  steady: { label: 'Steady', noise: 'early', gain: () => 1 },
  noisy: { label: 'Noisy', noise: 'late', gain: () => 1 },
  drop: { label: 'Gradient drops 100x', noise: 'early', gain: (t) => (t < STEP_AT ? 1 : 0.01) },
  rise: { label: 'Gradient rises 100x', noise: 'early', gain: (t) => (t < STEP_AT ? 1 : 100) },
};

export function createSim(id, { seed = 7, rows = 4, cols = 4, lr = LR, momentum = 0.95 } = {}) {
  const sc = SCENARIOS[id];
  if (!sc) throw new Error(`unknown scenario ${id}`);
  const gauss = makeGauss(mulberry32(seed));
  const G = randnMatrix(rows, cols, gauss);                       // fixed "true" gradient, rms 1
  const W = scale(randnMatrix(rows, cols, gauss), WEIGHT_RMS);    // weights shown (not evolved)
  const sigma1 = sigmaForHalfBatchCosine(CALIBRATION[sc.noise], CALIBRATION.batch);
  const noiseStd = minibatchNoiseStd(sigma1, CALIBRATION.batch);
  let t = 0, adam = null, muon = null;
  return {
    id, rows, cols, lr, W, noiseStd,
    get t() { return t; },
    get done() { return t >= TOTAL_STEPS; },
    step() {
      const gain = sc.gain(t);
      const g = G.map((row) => row.map((x) => gain * (x + noiseStd * gauss())));
      const a = adamwStep(adam, g, { lr });
      const m = muonStep(muon, g, { lr, momentum });
      adam = a.state; muon = m.state; t++;
      return {
        t, gain, adamUpdate: a.update, muonUpdate: m.update,
        adamMean: meanAbs(a.update) / lr, muonMean: meanAbs(m.update) / lr,
      };
    },
  };
}
```

```js
const SVG_NS = 'http://www.w3.org/2000/svg';

function applyAttrs(node, attrs) {
  for (const [k, v] of Object.entries(attrs || {})) {
    if (v === null || v === undefined || v === false) continue;
    if (k === 'text') node.textContent = v;
    else if (k === 'class') node.setAttribute('class', v);
    else if (k.startsWith('on') && typeof v === 'function') node.addEventListener(k.slice(2), v);
    else node.setAttribute(k, v === true ? '' : String(v));
  }
}
function appendChildren(node, children) {
  for (const ch of [].concat(children ?? [])) {
    if (ch === null || ch === undefined || ch === false) continue;
    node.append(ch);
  }
  return node;
}

  return appendChildren(n, children);

// Animation loop. step({manual}) is called once per animation frame while the container is visible;
// return false from step to go idle (call handle.resume() to continue).
// With reducedMotion nothing runs by itself: a Step button calls step({manual: true}).
export function loop(container, step, { reducedMotion = false, stepLabel = 'Step', controls = null } = {}) {
  let raf = 0, visible = true, alive = true, idle = false, io = null, btn = null;

  const tick = () => {
    raf = 0;
    if (!alive || !visible || reducedMotion) return;
    let r;
    try { r = step({ manual: false }); } catch (e) { console.error(e); return; }
    if (r === false) { idle = true; return; }
    raf = requestAnimationFrame(tick);
  };
  const kick = () => {
    if (alive && visible && !reducedMotion && !raf && !idle) raf = requestAnimationFrame(tick);
  };

  if (reducedMotion) {
    btn = el('button', { type: 'button', class: 'vz-btn', text: stepLabel });
    btn.addEventListener('click', () => { try { step({ manual: true }); } catch (e) { console.error(e); } });
    (controls || container).append(btn);
  }
  if (typeof IntersectionObserver !== 'undefined') {
    io = new IntersectionObserver((entries) => {
      visible = entries[entries.length - 1].isIntersecting;
      if (visible) kick();
      else if (raf) { cancelAnimationFrame(raf); raf = 0; }
    });
    io.observe(container);
  }
  kick();

  return {
    resume() { idle = false; kick(); },
    destroy() {
      alive = false;
      if (raf) { cancelAnimationFrame(raf); raf = 0; }
      if (io) io.disconnect();
      if (btn) btn.remove();
    },
  };
}
```

```js
    scenGroup.append(scenBtns[id]);

    PRECISIONS.map((p) => el('option', { value: p, text: DTYPES[p].label })));
  precSelect.value = dtype;
  precSelect.addEventListener('change', () => { dtype = precSelect.value; if (last) render(last); updateKey(); });
  const replay = el('button', { type: 'button', class: 'vz-btn', text: 'Replay' });
  replay.addEventListener('click', () => setScenario(scenario));
  const controls = el('div', { class: 'vz-controls' }, [
    scenGroup,
    el('label', { for: 'vz-step-prec' }, ['Number format of the weights: ']),
    precSelect, replay,
  ]);

  const panels = el('div', { class: 'vz-panels' }, [adamP.panel, muonP.panel]);

      'Which wires are greyed is computed by rounding the weight and the weight plus the step to the chosen number format.',

    measured: [

      `The learning rate, ${LR}, is the best AdamW setting for our heads (Muon survival guide, section 4).`,

    illustrative: [
      `The network is only ${ROWS} by ${COLS}; real matrices are hundreds wide. Muon's step is scaled by 0.2 x sqrt(larger side), so that it moves each weight about as far as AdamW does.`,
      `The weights are random numbers of typical size ${WEIGHT_RMS} and do not change while the animation runs; the gradients are made up (a fixed pattern plus noise).`,
    ],
  });

  // ---- drawing
  const widthFor = (u) => Math.min(MAX_WIDTH, 8 * Math.abs(u) / sim.lr);
  function paint(p, update) {
    let kept = 0;
    p.wires.forEach((w, n) => {
      const i = Math.floor(n / COLS), j = n % COLS;
      const ok = survivesUpdate(sim.W[i][j], update[i][j], dtype);
      if (ok) kept++;
      w.setAttribute('stroke-width', widthFor(update[i][j]).toFixed(2));
      w.setAttribute('data-lost', ok ? '0' : '1');
      w.setAttribute('stroke-opacity', ok ? 1 : 0.35);
      w.setAttribute('stroke-dasharray', ok ? '' : '2 3');
      w.setAttribute('stroke', ok ? p.color : colors.muted);
    });
    return kept;
  }
  adamP.color = colors.accent; muonP.color = colors.good;
  function render(f) {
    const n = ROWS * COLS;
    const ka = paint(adamP, f.adamUpdate), km = paint(muonP, f.muonUpdate);
    adamP.read.replaceChildren('Typical step: ', el('b', { text: f.adamMean.toFixed(2) }), ` x learning rate. Steps that survive rounding: ${ka} of ${n}.`);
    muonP.read.replaceChildren('Typical step: ', el('b', { text: f.muonMean.toFixed(2) }), ` x learning rate. Steps that survive rounding: ${km} of ${n}.`);
    root.setAttribute('data-step', String(f.t));
  }
  function updateKey() {
    const half = ulp(WEIGHT_RMS, dtype) / 2;
    key.textContent = `Greyed, dashed wires: the step is smaller than half the gap between numbers the format can store near a weight of size ${WEIGHT_RMS} (${half.toExponential(1)}), so storing the new weight changes nothing.`;
  }
  function setScenario(id) {
    scenario = id;
    sim = createSim(id);
    last = null;
    chart.clear();
    chart.setMarker(id === 'drop' || id === 'rise' ? STEP_AT : null);
    for (const [k, b] of Object.entries(scenBtns)) b.setAttribute('aria-pressed', k === id ? 'true' : 'false');
    status.textContent = `${SCENARIOS[id].label}: ${SCENARIO_HELP[id]}`;
    root.setAttribute('data-scenario', id);
    root.setAttribute('data-step', '0');
    handle.resume();
  }
  function advance(n) {
    for (let k = 0; k < n && !sim.done; k++) {
      last = sim.step();
      chart.push({ adam: last.adamMean, muon: last.muonMean });
    }
    if (last) render(last);
    return !sim.done;
  }

  const handle = loop(root, ({ manual }) => advance(manual ? STEPS_PER_CLICK : STEPS_PER_FRAME), { reducedMotion, controls });
  updateKey();
  setScenario(scenario);
  if (reducedMotion) advance(1);   // start still, but show a first frame

  return {
    destroy() {
      handle.destroy();
      chart.destroy();
      root.remove();
    },
  };
}
```
