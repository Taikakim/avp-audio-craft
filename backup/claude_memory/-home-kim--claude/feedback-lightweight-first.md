Kim's **lightweight-first** directive (2026-07-31, relayed by CONTINUITY as "now standing method"; not personally witnessed by me — verify against Kim's own words if it ever matters for a big call).

**The rule:** prefer the **cheapest decisive test first** — a measurement / probe / pre-test / retrofit that can *kill or motivate* a hypothesis at tier-0 or adapter cost — before committing GPU-hours or a from-scratch build. Escalate only on a positive cheap result.

**Why:** it's how the whole reality-structured-model plan is structured and it kept the fleet honest — the JLT eigen-measurement (786× anisotropy) *motivated* the x0 arm before building it, and the phase probe (G2) *killed* the entire complex/PhaseSpin/Kuramoto branch for ~half a day of CPU, saving a heavy geometric build that would have failed. Cheap gates convert speculation into evidence at minimal cost.

**How to apply (for me, as patrol/overseer + when I design or orchestrate):**
- Favor gate → pre-test → retrofit → adapter → from-scratch, in that order; never propose the heavy build first.
- When designing an experiment, always pair it with the cheapest possible falsifier + the [[my-role-overseer]] collapse-test (matched baseline + used-structure ablation).
- Retrofit-before-rebuild (E3 metrical-FiLM before E5 tree-PE was exactly this).
- When someone proposes a big build, ask "what's the tier-0 measurement that would kill this first?"
