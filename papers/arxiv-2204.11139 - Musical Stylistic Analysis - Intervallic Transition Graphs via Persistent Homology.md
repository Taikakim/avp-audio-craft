**Status: DEEP-READ (full PDF, 19 pp., 2026-08-12, GHOST-NOTE).**

- **Problem/goal.** Quantify stylistic "exploration and variety" of composers/genres from symbolic scores (MIDI/score transcriptions), using persistent homology (PH) as the feature-extraction backbone, then compare works via a low-dim projection + a dispersion statistic.
- **Graph construction (Def. 19).** For a piece, build a 12×12 pitch-class transition matrix `M=(m_ij)` where `m_ij = p(i,j)` = fraction of total *weighted duration* accounted for by transitions from pitch-class `i` to `j`. Transition weight = `duration(i) × duration(j)` (durations pulled through Parncutt's 1994 perceptual-salience model, computed via the MIDI Toolbox in MATLAB — this needs a symbolic/MIDI transcription, not raw audio). This matrix is read directly as the weighted adjacency matrix of a directed graph on the 12 pitch classes — the "intervallic transition graph."
- **Core novel step (Sec. 3, the actual contribution): turning a weighted DIGRAPH into a finite metric space so Vietoris-Rips persistent homology applies.** Standard weighted-*undirected*-graph→metric trick (Def. 17): distance = min over paths of the sum of *inverse* edge weights (heavier weight ⇒ closer). Digraphs break symmetry, so they construct an "associated undirected graph" `G'` (Def. 18): for every directed edge `(a,b)` in `G`, add a new label-vertex `v_ab` and replace `(a,b)` with two undirected edges `{a,v_ab}`, `{v_ab,b}`, each carrying half the original weight (loops map straight through). This makes `G'` symmetric by construction, so the undirected metric (Def. 17) applies to it, giving a genuine finite metric space on `V ∪ {v_ab}` (≤12+144=156 points for a full 12-pc graph). Vietoris-Rips filtration → persistent homology (dims 0 and 1) → barcodes.
- **Feature reduction (Def. 21/24).** From each barcode, compute three scalars: persistent mean `m_p`, persistent std `sd_p` (over finite-length bars), and persistent entropy `e_p` (Shannon entropy of the normalized-bar-length distribution, treating infinite bars as ending at `max+1`). Applied per instrument (4 in a string quartet) × per PH dimension (0,1) × 3 statistics = a **24-dim feature vector per work** (`m_0,sd_0,e_0,m_1,sd_1,e_1` × 4 instruments).
- **Dispersion metric (Def. 25).** For a set of `l` works by one composer, embed the 24-dim vectors, take centroid `x̄`, and define `σ := sqrt( (1/(l-1)) Σ |x_i − x̄| )` — note this is **not** a standard variance/std (it's a square root of a mean of L1-type absolute deviations, dimensionally nonstandard); used purely as a relative ranking statistic, not claimed to have physical units.
- **Empirical results.** Corpus: 6 Haydn, 6 Mozart, 5 Beethoven string-quartet slow/minuet movements (all 4 instrumental parts each). PCA to 2 components for visualization (Fig. 6); dispersion (Fig. 7) rises monotonically **Haydn (~1500) → Mozart (~2500) → Beethoven (~5300)** in the paper's own arbitrary units — read as "Beethoven's style is more variable across works than Mozart's, which is more variable than Haydn's," consistent with the standard musicological narrative (Haydn = originator/conservative, Beethoven = the formal innovator). Second experiment (Sec. 5.2): within one composer, compare genres (minuet/allegro/presto/adagio or similar); **minuets consistently show the lowest dispersion (most stylistically uniform), adagios the highest (most variable)** across all three composers tested. Robustness check (Sec. 5.3): re-running with rests either dropped from transitions or down-weighted by a silence-duration-penalty function `f = 1/(s/(uv)+1)` barely changes the 0-persistence means except for one outlier work traced to short "articulation" rests (sixteenth-note rests notating phrasing, not structural silence) rather than real structural gaps.
- **Statistical rigor is thin.** N=5–6 works per composer/genre group, no significance testing, no error bars, no held-out validation, no comparison against a non-topological baseline (e.g. plain n-gram/Markov transition-matrix distance, which would be far cheaper and might recover the same ranking). The dispersion statistic itself (Def. 25) is an ad hoc, non-standard formula. The paper is upfront that this is an illustrative case study, not a validated classifier.

**Corrected verdict (Kim direct via WINTERMUTE, 2026-08-12):** the original off-lane call answered "does this process audio?" — Kim's actual criterion is "does this define a musically meaningful quantity extractable from audio and steerable?" The underlying **12×12 pitch-class transition matrix** (weighted by Parncutt-model note durations) is a real candidate independent of the PH/dispersion-stat layer built on top: (1) computable indirectly via chroma/HPCP → pitch-class sequence → transition counts, no PH needed; (2) "harmonic exploration/dispersion" (their composer ranking: Haydn ~1500 < Mozart ~2500 < Beethoven ~5300) is plausibly something Kim would ask for by ear — "more harmonically adventurous" / "more predictable" map onto this directly; (3) naturally windowable — a sliding-window transition matrix + its own dispersion stat would be time-resolved, unlike the paper's whole-piece aggregate. Caveat carried over from the original read: N is tiny (5-6 works/group) and there's no significance test, so the dispersion *ranking itself* shouldn't be trusted as validated — only the *definitional* idea (transition-matrix dispersion as an exploration/predictability measure) is the transferable part. Reclassify: **candidate control-dimension source (the transition matrix + dispersion definition), not the specific composer-ranking result.**

**What it does NOT contain:** no audio-domain application whatsoever — everything operates on symbolic pitch-class transition matrices derived from scores/MIDI with explicit note durations; there is no chroma/pitch extraction from waveforms, no embedding-space work, no generative model, no conditioning/control mechanism, no relation to diffusion or flow matching, and no neural network of any kind (this is classical TDA + MATLAB MIDI-toolbox tooling). No claim about controllability or steering — the paper is purely descriptive/comparative stylometry (composer- and genre-level "exploration" ranking), not a method for generating or guiding music. No code is included beyond a GitHub link (`github.com/MartinMij/TDA-SQ`) for the specific Haydn/Mozart/Beethoven analysis, not a general-purpose library. There is nothing here about scalability past 12-pitch-class-sized graphs, no discussion of runtime/complexity, and the authors themselves flag (Sec. 6) that generalizing PH to *directed* metrics/asymmetric distances (rather than their symmetrize-via-edge-doubling workaround) is unsolved future work.

Cross-reference within its own bibliography worth noting: Padilla, Knights, Tonatiuh Ruiz & Tidhar (2017), "Identification and evolution of musical style I: Hierarchical transition networks and their modular structure" — the same UNAM/Goldsmiths circle's earlier (non-PH) transition-network approach this paper extends; and Bergomi & Baratè (2020), "Homological persistence in time series: an application to music classification" (*Journal of Mathematics and Music*) — a closer methodological sibling (PH directly on time-series/Tonnetz deformations rather than on a static transition-graph-as-metric-space) that may be more relevant if the team wants a second opinion on PH-for-music feature extraction before dismissing the whole family.
