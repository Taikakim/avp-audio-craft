# UNISON: A Unified Sound Generation and Editing Framework via Deep LLM Fusion (2605.31530) — light pass

Li, Xu, Su, Liu, Rao, Wang et al. (CUHK/PolyU/CityU/HKUST/Tsinghua/Huawei), arXiv 2605.31530v2, 2 Jun 2026.
PDF: `2605.31530v2-UNISON- A Unified Sound Generation and Editing Framework via Deep LLM Fusion.pdf`.
A unified speech+sound MM-DiT that looks SA3-adjacent on the surface (flow-matching, MM-DiT, CFG) but is built on a mel-spectrogram continuous VAE, not a waveform latent — so it fails one of SAO's two hard filters and mostly reports off-target (TTS/cloning) results; one conditioning-architecture idea is worth a mental note.

## What it contains
- A single 621M-732M-param flow-matching MM-DiT checkpoint that handles T2A, zero-shot bilingual (EN/ZH) TTS and speaker cloning, gender-controlled TTS, mixed speech+sound generation (T2AS), scene-level audio editing (add/remove/replace), speech-in-scene editing (insert/delete/rewrite), and timed/temporal composition - all through the same VAE, DiT weights, and forward pass.
- **Layer-wise deep LLM fusion**: a frozen Qwen2.5-Omni-7B instruction encoder is run once; hidden states from L uniformly-sampled layers are each linearly projected into the depth-matched MM-DiT double-stream block (shallow DiT blocks <- shallow/lexical Qwen layers, deep blocks <- deep/semantic layers), rather than broadcasting one final-layer embedding everywhere. Ablation (Table 8) shows this beats single-penultimate-layer conditioning on both FD (20.46 vs 22.71) and CLAP (0.180 vs 0.175) at matched compute.
- **Unified task encoding**: task identity is a single per-frame mask channel `m ∈ {0,1,2}` (generation/editing/TTS) concatenated with the VAE-encoded source/reference latent (zeros for pure generation); editing is thus just conditional generation, with no inversion, no separate mel encoder, no task-specific decoder.
- Underlying substrate: MMAudio's continuous VAE (waveform -> mel-spectrogram -> latent z, C=20 or 40 channels, 44.1kHz or 16kHz variants), double-stream (not single-stream) joint attention shown by ablation to be essential (single-stream collapses to worst FD 23.19).
- Explicitly does not target music generation (data-licensing reasons, cited as future work) and supports only English/Chinese speech.

## What this means for us
- **Fails SAO's hard filter #2**: the VAE is mel-spectrogram-based (MMAudio VAE), not a waveform-native latent like SAME. The concrete architecture - channel-concat scheme sized to that VAE, double-stream token layout, the specific fusion projector - does not port as a drop-in to SA3's waveform-latent DiT; anything worth taking must be re-derived onto T5Gemma cross-attention/AdaLN/local-additive conditioning, not copied.
- **One idea worth a future ablation, not a gap being missed**: depth-matched multi-layer text conditioning (feed several T5Gemma layers to different DiT depths instead of one final embedding to every block) has a quantified, if modest, benefit in this paper's setting. Testing whether SA3's cross-attention conditioning already captures this (or would benefit from layer-matched injection) is a plausible small experiment for the book's prompt/conditioner chapter - not urgent, not previously covered by any SAO artifact, but also not a novel idea in the broader literature (the paper itself cites Tang et al. 2025 and Cai et al. 2025 doing this for text-to-image).
- **Editing-as-conditional-generation via channel concat + task mask** independently reconfirms, rather than extends, ideas SAO already ships (Longform's SDEdit-style re-anchoring, the book's inpaint/mask/schedule chapter) - no new control mechanism for SA3 here.
- The bulk of the paper's contribution and all of its strongest results (zero-shot TTS/cloning, gender control, phoneme-free bilingual speech, speech-in-scene editing) is TTS/speech-domain work with no analog in SA3's scope (music/sound-effect generation, no speech). This remains uniquely outside SAO's problem and carries no transfer value beyond the general "unify tasks via mask channel + shared VAE" architectural pattern already known.
