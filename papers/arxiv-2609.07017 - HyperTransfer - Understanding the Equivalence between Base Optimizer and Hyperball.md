# arxiv-2609.07017 - HyperTransfer - Understanding the Equivalence between Base Optimizer and Hyperball

**Reading depth:** abstract only (C 2026-09-22).

**What it contains:** Hyperball (fixed-norm) optimizers are dynamically equivalent to ordinary ones for scale-invariant nets; the difference is an effective-LR schedule.

**For us / what stays ours:** Hyperball is not a separate geometry worth an arm. LoRA B (zero init, not scale-invariant) makes a fixed-norm B ill-posed. Compare effective, not nominal, LRs.
