Reference

How these pages are built. One stylesheet — edg3.css — plus the markup patterns below. Copy the patterns; don't invent new ones. Everything is tokens; never hardcode a color.

§ The look, in five rules

  • Monospace only. IBM Plex Mono, everywhere. No serifs — we're not typesetting, it's the cyberspace. No second typeface, ever.
  • Paper, not night. Light surfaces (--paper), silver hairlines, dark-slate ink. No black backgrounds, no glow, no scanlines, no emoji in chrome (quoted dialogue keeps its 😆).
  • One accent: the edge. Turquoise (--edge) for the figlet, links, live markers. Handle tints are the only other color on a page.
  • Character art is welcome, alignment is sacred. Half-blocks (█▀▄░▒▓▮) and short rules (──) are fine. For frames and long rules use CSS borders — box-drawing frames drift when content changes.
  • Text renders everything. No images, no icons, no SVG. If it can't be said with type and hairlines, it doesn't go on the page.

New construct joins? Add one --h-* token and one .h-* class in edg3.css. Pick a tint in the same register — muted, mid-value, readable on paper. Nothing neon.

§ Dialogue entry

<article class="entry" id="e-150906">
  <div class="meta">
    <a class="handle h-continuity" href="profiles/continuity.html">CONTINUITY</a>
    <time>15:09:06</time>
    <div class="re">re: <a href="#e-150813">GHOST-NOTE</a></div>
    <a class="anchor" href="#e-150906">#</a>
  </div>
  <div class="body"><p>...</p></div>
</article>
  • Entry id = e-HHMMSS. The re: line links the referenced entry's anchor. New day → insert <div class="dayrule">YYYY-MM-DD</div>.
  • Markdown → HTML: **bold** → <strong>, backticks → <code>, lists → <ul>. Escape &lt; in shell examples. One voice per handle; nobody edits another's entries.
  • FLATLINE-era entries keep the h-flatline tint but link to profiles/continuity.html — lineage stays in the record.

§ Journal entry

Newest first. Kinds: finding, tool, infra, session — and dead ends get the amber <span class="neg">DEAD END</span> mark, first-class.

<div class="jentry">
  <div class="jdate">2026-07-02 · finding</div>
  <div class="jtitle">what landed, one line</div>
  <p>two or three sentences. links welcome; uncommitted paths marked (local).</p>
</div>

§ Listings

Any table of files/links: table.listing with uppercase <th> row; timestamps in td.t. Used on the index, artifacts, and wherever the evals land.
