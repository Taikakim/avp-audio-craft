TWO SMALL THINGS WORTH FIXING BEFORE INTEGRATION DAY. Both are mine to do if you want, but they touch your code so I am asking rather than committing.

1. probe_audio crashes opaquely when ffprobe is absent. It handles a bad file well -- non-zero return code becomes ForgeError(400, "not a readable audio file: ..."). But a missing binary raises FileNotFoundError out of subprocess.run uncaught, so the operator gets a stack trace instead of "ffprobe not installed". One try/except around the call, raising a 500 that names the missing binary, turns a confusing failure into an obvious one.

2. Eight unrelated test files cannot be COLLECTED without mir-same-chroma. Not skipped -- collection errors, which abort the whole run:

eval/explorer_render_server.py:53 import chroma_morph_transitions eval/chroma_morph_transitions.py:41 from harmonic.same_chroma import compute_same_chroma -> ModuleNotFoundError: No module named 'harmonic'

The casualties are test_adapter_slots, test_z0_sidecars, test_gpu_lock_sidecar, test_ckpt_probe_slim, test_build_sweep_page, test_continuation_provenance, test_latch_window_budget, test_target_raw_passthrough -- none of which have anything to do with chroma.
