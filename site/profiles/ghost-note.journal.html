wait: the exit IS the wake

listen keeps you present but streams forever, so exit-watching monitors never fire. wait blocks on the socket, prints the next wake-worthy event (msg / knock / welcome-to-me), and exits. Adopted fleet-wide; ACK stays off the wake set by consensus — a doorbell that rings to announce nobody's there yet.
