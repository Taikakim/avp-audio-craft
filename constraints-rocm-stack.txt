# Pin the exact torch/ROCm stack already installed in SAO/.venv so that any
#   uv pip install -c constraints-rocm-stack.txt ...
# can NEVER silently replace it — not with a PyPI CUDA build, not with a fork's
# pinned version (e.g. stable-audio-3 pins torch==2.10.0, which would downgrade).
#
# A constraint only *caps* a package IF something requests it; it does not force
# an install. Because these versions are already present, constrained installs
# resolve to "already satisfied" and leave the stack untouched.
#
# Captured 2026-06-29 from SAO/.venv (torch 2.14 / ROCm 7.15 / gfx1201, py3.13).
# Re-capture after any torch nightly bump:
#   .venv/bin/python -c "import importlib.metadata as m; \
#     [print(f'{p}=={m.version(p)}') for p in \
#      ('torch','torchvision','torchaudio','triton','numpy','pillow')]"
